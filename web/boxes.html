Find any box by ID or batch, see where it is and how long it has been there, and log exceptions.

Every physical box gets its own ID when it is registered, for example SG-BGA-261025-0007-K:

Parts of a box ID
PartExampleMeaning
PrefixSGSimply Garlic
Product codeBGAThree-letter product code (see list below)
Date261025Date the box was registered, as YYMMDD (25 Oct 2026)
Box number0007The 7th box of that product registered that day
Check characterKCalculated from the rest of the ID. If a label is damaged or a character is mistyped, the check fails and the scan is rejected instead of matching the wrong box.
